# C-RAM Fire Control Architecture Simulator

Egyetemi beadandóként (Miskolci Egyetem - Programtervező Informatikus BSc / Számítógép Architektúrák) készített multi-page weboldal, amely egy szárazföldi légvédelmi gépágyú tűzvezető számítógépének hardveres felépítését, hibatűrését és működési elveit mutatja be taktikai, sötét terminál stílusban.

## 🚀 Főbb funkciók és technológiák
* **Tech Stack:** HTML5, CSS3 (Reszponzív Media Queries), Vanilla JavaScript.
* **Boot Animáció:** Filmbe illő, gépelős terminál indítóképernyő SessionStorage alapú intelligens memóriával (csak az első belépéskor vagy frissítéskor fut le).
* **Hardveres Architektúra Elemzés:** Lockstep redundancia, RTOS (Valós idejű operációs rendszer), ECC memória és EMP-védelem részletes bemutatása.
* **Összehasonlító Modul:** Hardver-specifikációk összehasonlítása (Légvédelmi tűzvezető vs. High-End Gamer PC vs. Taktikai drónvezérlő vs. Irodai PC).
* **Fogalomtár:** Részletes lexikon a kritikus szakmai kifejezésekhez.
